| Variable          | Where to Find It                                                                                                                                                          |
| :---------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `AUTH_SECRET`     | Already generated by `npx auth secret` above ✅                                                                                                                           |
| `AUTH_RESEND_KEY` | Go to [resend.com/api-keys](https://resend.com/api-keys) → Create API Key → copy it                                                                                       |
| `DATABASE_URL`    | Go to your [Neon Dashboard](https://console.neon.tech) → Select your project → Connection Details → copy the connection string (make sure it includes `?sslmode=require`) |
| `CF_ACCOUNT_ID`   | Go to [Cloudflare Dashboard](https://dash.cloudflare.com) → look in the right sidebar on the main page → "Account ID"                                                     |
| `CF_STREAM_TOKEN` | Go to [Cloudflare API Tokens](https://dash.cloudflare.com/profile/api-tokens) → Create Token → use the "Edit Cloudflare Stream" template → copy the token                 |
